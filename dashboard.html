Add AI models

Provider keys stay on your server and are never sent to users’ browsers. Add a key to .env, save the file, restart the ZetaCore server, then refresh this page.

Gemini

Get an API key from Google AI Studio, then set it in your local .env file:

GEMINI_API_KEY=your_gemini_api_key

OpenRouter

Create an OpenRouter API key, then set:

OPENROUTER_API_KEY=your_openrouter_api_key

Custom OpenAI-compatible model

Add a provider definition and its matching key variable. Duplicate entries to add multiple models.

CUSTOM_MODELS=[{"id":"my-model","label":"My Model","mode":"instant","url":"https://api.example.com/v1/chat/completions","model":"vendor/model-id","apiKeyEnv":"MY_MODEL_API_KEY"}]
MY_MODEL_API_KEY=your_provider_api_key

Use mode as instant or deep. Never paste API keys into chat or browser code.
